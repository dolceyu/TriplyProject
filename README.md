# Triply — Платформа для спільного планування подорожей

Triply — це сучасний веб-додаток, створений для того, щоб спростити організацію групових поїздок. Головна фішка проєкту — інтелектуальна система підбору попутників на основі математичного апарату.

---

## Основні можливості

- Smart Match (FCA Algorithm): Унікальна система підбору попутників, що використовує Формально-концептуальний аналіз. Система аналізує спільні інтереси та пропонує ідеальних кандидатів для вашої пригоди.
- Командна робота: Можливість створювати поїздки, запрошувати друзів за кодом та розподіляти ролі (Гід та Учасники).
- Маршрут та Бронювання: Зручне управління квитками, житлом та планом поїздки в одному місці.
- Birthday Awareness: Система автоматично нагадує про дні народження друзів під час подорожі.
- Гнучке управління: Можливість покинути подорож або змінити гіда в реальному часі.

## Технологічний стек

### Frontend
- React.js — ядро інтерфейсу.
- Tailwind CSS — стилізація та адаптивність.
- Lucide React — набір сучасних іконок.
- Axios — взаємодія з API.

### Backend
- Python (FastAPI) — високопродуктивний сервер.
- SQLAlchemy — ORM для роботи з базою даних.
- PostgreSQL/SQLite — зберігання даних користувачів та поїздок.

## Як запустити проєкт

### 1. Бекенд (Python)
cd backend
python -m venv venv
source venv/scripts/activate  # для Windows
pip install -r requirements.txt
uvicorn main:app --reload

### 2. Фронтенд (React)
cd frontend
npm install
npm run dev

# Triply — Платформа для спільного планування та оптимізації подорожей

Triply — це сучасний веб-додаток для організації групових поїздок, який поєднує інструменти командної роботи з інтелектуальними алгоритмами. Система вирішує задачі підбору ідеальної компанії, генерації ідей за допомогою штучного інтелекту та математичної оптимізації маршрутів.

---

## Основні можливості та алгоритми

- Інтелектуальна побудова маршрутів та кластеризація точок: Система "Смарт-розподілу", яка автоматично аналізує обрані локації та групує їх у кластери для оптимізації логістики та економії часу в поїздці.
- Поради та генерація від Штучного Інтелекту: Інтегрований ШІ-асистент, який допомагає з плануванням, пропонуючи релевантні місця, ресторани та активності для конкретної поїздки.
- Smart Match (алгоритм на базі ФКА): Унікальна система підбору ідеальних попутників з використанням Формально-концептуального аналізу. Алгоритм вираховує перетин інтересів користувачів і автоматично генерує цільові запрошення (інвайти).
- Спільне планування та ролі: Розділення прав доступу на "Гіда" (організатора) та звичайних учасників. Можливість передачі прав гіда та гнучкого виходу з поїздки.
- Управління логістикою: Централізоване зберігання інформації про бронювання квитків, житла та загального розкладу.
- Динамічний контекст: Автоматичне відстеження днів народження учасників, які випадають на дати подорожі.

---

## Технологічний стек

### Frontend
- React.js — побудова користувацького інтерфейсу.
- Tailwind CSS — компонентна стилізація.
- Axios — асинхронна взаємодія з REST API.
- Інтеграція інтерактивних карт для відображення кластеризованих маршрутів.

### Backend
- Python (FastAPI) — високопродуктивний асинхронний сервер.
- SQLAlchemy — ORM для взаємодії з реляційною базою даних.
- Алгоритми кластеризації просторових даних та ФКА.
- Інтеграція з API штучного інтелекту для генерації пропозицій.
- PostgreSQL / SQLite.

## Як запустити проєкт

### 1. Backend
cd backend
python -m venv venv
source venv/scripts/activate  # для Windows
pip install -r requirements.txt
uvicorn main:app --reload

### 2. Frontend
cd frontend
npm install
npm run dev
